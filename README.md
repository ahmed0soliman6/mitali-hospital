# نظام إدارة مستشفى لجنة زكاة ميت على التخصصي

نظام إدارة طبي وإداري شامل تم تحويله إلى **Web App / PWA** احترافي باسم:
**نظام إدارة مستشفى لجنة زكاة ميت على التخصصي**.


## ما تم تنفيذه

- واجهة تشغيل Web App متجاوبة للكمبيوتر والهاتف.
- دعم **PWA** مع `manifest.webmanifest` وإمكانية تثبيت النظام كتطبيق.
- Service Worker في `sw.js` للتخزين المؤقت وتشغيل الواجهة الأساسية عند انقطاع الإنترنت.
- صفحة `index.html` أصبحت نقطة الدخول الرئيسية للتطبيق، مع شاشة تحميل احترافية وزر تثبيت التطبيق.
- أيقونة تطبيق `icon.svg` وهوية لونية متوافقة مع النظام.
- النظام مبني بـ HTML/CSS/JavaScript خام، مع Firebase Authentication وCloud Firestore وIndexedDB للكاش المحلي والعمل عند ضعف الاتصال.

## الأقسام الموجودة في النظام الأصلي

- يومية العيادات + ملفات مرضى العيادات
- يومية الأسنان + ملفات مرضى الأسنان
- يومية العمليات
- يومية التحاليل مع قائمة أنواع قابلة للتخصيص ودعم أكثر من تحليل للمريض
- يومية الأشعة مع قائمة أنواع قابلة للتخصيص ودعم أكثر من نوع أشعة للمريض
- الوارد / المنصرف / دفتر الخزينة
- المرتبات والمستحقات
- التقارير اليومية / الشهرية / السنوية
- إدارة المستخدمين والصلاحيات الدقيقة
- سجل النشاط Audit Log

## بنية المشروع

```text
index.html              ← نقطة دخول Web App / PWA
manifest.webmanifest     ← تعريف التطبيق للتثبيت
sw.js                    ← Service Worker / Offline shell
icon.svg                 ← أيقونة التطبيق
README.md
```

## النشر

المستودع مجهز للنشر عبر GitHub Pages. بعد تفعيل Pages على فرع `main` ومجلد الجذر `/` يمكن فتح الموقع من رابط GitHub Pages الخاص بالمستودع.

## ملاحظات الأمان

المستودع خاص، ويعتمد النظام على Firebase Authentication وقواعد Firestore الآمنة. قبل إدخال بيانات مرضى حقيقية يجب مراجعة قواعد Firestore، وتغيير كلمات المرور المؤقتة، وعدم رفع نسخ احتياطية تحتوي بيانات مرضى إلى المستودع.

هذا المشروع ملك خاص لمستشفى لجنة زكاة ميت على التخصصي. جميع الحقوق محفوظة.
